手机 / 平板配对

Android 上不需要另装壳：手机浏览器直接打开你正在跑的 dsh web，再「添加到主屏幕」就是全屏应用，商店里的 PWA 安装方式即可。

1. 粘贴 dsh 启动时打印的地址

在终端里启动 dsh web 的那一行 dsh web: … 里就有；这个 token 只用于换取手机自己的 30 天会话 cookie。

2. 手机 / 平板操作

  1. 用系统相机或扫码功能扫描二维码，在浏览器中打开。
  2. 页面跳转到不带 token 的地址后，用浏览器菜单「添加到主屏幕 / 安装应用」。
  3. 之后从桌面图标启动即可，cookie 有效期约 30 天；过期后重新配对一次。
手机需要能访问电脑的地址（同一局域网，或已做端口转发）。壳本身不代理流量；dsh web --host 绑定的就是手机要连的地址。
